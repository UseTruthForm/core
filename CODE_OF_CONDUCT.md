# Code of Conduct

TruthForm follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository, its issues, pull requests and discussions, and
anywhere someone speaks for the project.

## Reporting

Write to **admin@sallux.dev**. Reports are read only by the maintainers, and
kept confidential. If a maintainer is involved, say so, and they take no
part in handling it.

The maintainers decide what follows, using the covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
from a private warning to a permanent ban.
